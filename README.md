# ml-prediction-salaire
ml‑prediction‑salaire est un projet de Machine Learning visant à prédire le salaire d’un individu à partir de variables telles que l’expérience, le niveau d’étude, le secteur d’activité ou la localisation. Le projet suit un pipeline Data Scientist complet : collecte, nettoyage, EDA, modélisation, évaluation et déploiement.
